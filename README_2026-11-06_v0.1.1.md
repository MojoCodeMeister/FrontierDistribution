# FrontierDistribution — Stage 1 v0.1.0

**Working logical identity model, not a claim about Frontier's deployed topology.**

Included: logical ERD, authority/assumption documents, synthetic catalog, C# .NET 8 domain/contracts/identity resolver, dependency-free executable test harness.

## Prerequisite
.NET SDK 8+ on Windows (`dotnet --version`). No NuGet test framework packages are necessary.

## Validate and run
From project root:

```powershell
dotnet build .\tests\Frontier.Identity.Tests\Frontier.Identity.Tests.csproj
dotnet run --project .\tests\Frontier.Identity.Tests\Frontier.Identity.Tests.csproj
```

Expect 10/10 PASS, process exit 0. Actual results must be recorded after running; compile/test execution was unavailable in the packaging environment.

## Design boundaries
- No operational ERP/webstore/warehouse, SQL physical schema, UI or inventory quantity logic yet.
- Entity records and mappings use synthetic identities; illustrative strings are not actual Frontier identifiers.
- Catalog and API contracts are candidate implementation artifacts, not approved SB state.
- Q24 S1/S2/S3 and other SB governance remain untouched.
